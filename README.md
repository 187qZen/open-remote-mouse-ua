# PC Remote

Безкоштовна заміна Remote Mouse: телефон (iOS і Android) керує Windows-ПК через браузер.
Нативний застосунок на телефоні не потрібен, інтерфейс роздає сам сервер на ПК.

## Можливості

- Тачпад: рух, клік, правий клік, скрол, перетягування (тап і тягти, або кнопка «Тягти»)
- Медіа: play/pause, наступний/попередній, гучність, mute
- Відео (YouTube): перемотка 10 с, повний екран, субтитри, швидкість, наступне/попереднє
- Введення тексту з телефона (включно з українською)
- Список запущених вікон з іконками, перемикання та закриття
- Кілька ПК: перший екран зі списком комп'ютерів і статусом «у мережі»
- Автоматичне підключення за іменем ПК (`ІМ'Я.local`), без IP-адрес
- Розрив зв'язку при блокуванні телефона (економія батареї)
- Іконка в треї, автозапуск при вході в Windows

## Встановлення

Потрібні Windows 10/11 і Python 3.10+ (з галочкою «Add python.exe to PATH»).

1. Завантаж або склонуй цей репозиторій, наприклад у `C:\PCRemote`.
2. *(Необов'язково)* Запусти `build.bat`, щоб зібрати `PCRemote.exe`.
3. Запусти `install_autostart.bat` **від імені адміністратора**.
   Він створить автозапуск, відкриє порт 8765 для приватних мереж і стартує сервер.
4. Клікни іконку PC Remote в треї, там адреса й PIN.
5. На телефоні (той самий Wi-Fi) відкрий `http://ІМ'Я-ПК.local:8765`, введи PIN
   і додай сторінку на головний екран (Safari: «Поділитися → На початковий екран»).

Видалити автозапуск: `uninstall_autostart.bat` (від адміністратора).

## Безпека

- Доступ захищений PIN-кодом (файл `config.json`, створюється при першому запуску).
- Трафік не шифрується (HTTP), користуйся лише у довіреній домашній мережі.
- Не відкривай порт 8765 в інтернет.

## Обмеження

- Лише Windows.
- Вікна програм, запущених від адміністратора, звичайний процес не може перемкнути чи ввести в них текст.
- Адреса `.local` на деяких Android-пристроях не працює, використовуй IP-адресу.
